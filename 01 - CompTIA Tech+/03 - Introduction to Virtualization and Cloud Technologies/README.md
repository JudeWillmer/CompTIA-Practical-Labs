# Introduction to Virtualization and Cloud Technologies

## Overview

This lab covers the practical tasks I completed to explore **virtualization and cloud technologies** using **Amazon Web Services (AWS)** and **Microsoft Azure**. I worked with **Infrastructure as a Service (IaaS)** to create and configure cloud-based virtual machines, virtual networks, subnets, storage, and supporting networking resources across both cloud platforms.

I used the **AWS Management Console** to configure **Virtual Private Clouds (VPCs)**, subnets, and networking components before deploying and remotely accessing a **Windows Server EC2 instance**. I also explored the **Microsoft Azure portal**, deployed and connected to a **Windows Server virtual machine**, and reviewed additional VM configuration options including storage, compute sizing, and backup. These tasks gave me practical experience with cloud infrastructure provisioning, virtual networking, remote administration, and managing virtualised computing resources.
